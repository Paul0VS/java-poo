# Java POO — Desafios

Repositório com exercícios práticos desenvolvidos durante meus estudos de **Java e Programação Orientada a Objetos (POO)**.

## 📚 Desafios

### 1. Pessoa
Classe com um método que exibe a mensagem "Olá, mundo!" no console.

### 2. Calculadora
Método que recebe um número como parâmetro e retorna o dobro desse valor.

### 3. Música
Classe com atributos para armazenar informações sobre uma música, registrar avaliações e calcular a média das notas.

### 4. Carro
Classe com atributos de modelo, ano e cor, além de métodos para exibir a ficha técnica e calcular a idade do veículo.

### 5. Aluno
Classe com atributos de nome e idade e um método para exibir as informações do aluno.

## 🧠 Conceitos praticados

- Classes e objetos
- Atributos e métodos
- Instanciação de objetos
- Parâmetros e retorno de métodos
- Manipulação de dados
- Programação Orientada a Objetos (POO)

## 🎯 Objetivo

Praticar os fundamentos da linguagem Java e desenvolver conhecimentos em Programação Orientada a Objetos por meio de exercícios.
